# Watchdog permission correction

The built-in GitHub workflow token cannot list repository variables through the
REST endpoint (hosted run 43332825744 returned 403). This observer-only successor
receives the existing variable values from GitHub's workflow expression context.
It requests no broader token or new credential. Missing or enabled predecessor
gates remain closed. The original collector, its marker, all prior files and
all frozen science remain byte-identical. The same single-writer checks, bounded
claim ledger, recovery decisions and fixed final calculation are retained.

The complete mocked observer path fails on any unexpected request, so it proves
recovery can proceed without the forbidden variables API. Hosted execution is
also required before the permission correction is considered verified.
